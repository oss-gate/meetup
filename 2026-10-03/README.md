# OSS Gate Pass 2026

## イベント概要

OSS Gateの設立10周年を記念した、初のオフラインカンファレンスです。これまでの活動や参加者の経験を振り返り、今後のOSS Gateについて考える場として開催されました。

- 日時：2026年10月3日（土）13:00〜17:00（13:00開場、13:30開会）
- 会場：株式会社アンドパッド ANDPAD STADIUM（住友不動産東京三田ガーデンタワー37階）
- 住所：東京都港区三田3-5-19
- 参加費：無料
- イベントページ：[OSS Gate Pass 2026 - OSS Gate 10周年記念オフラインカンファレンス！](https://oss-gate.doorkeeper.jp/events/197019)

プログラムには、OSS Gateの開催経験や参加を通じた変化、日常とOSSの関わりなどをテーマにしたトーク、おやつを交えた自己紹介、10年後のOSS Gateを考えるディスカッションが組まれました。終了後の17:00〜19:00には懇親会も設けられました。
